# 卡通风格视觉说明

## 风格关键词
- 儿童向
- 轻游戏化
- 暖白背景
- 大圆角
- 糖果色点缀
- 软阴影
- 插画卡片

## 色板
| 语义 | 颜色 | 用途 |
| --- | --- | --- |
| 主背景 | `#fffaf5` | 页面底色、弹窗底板 |
| 卡片底色 | `#ffffff` | 卡片与浮层主体 |
| 主文字 | `#1f2937` | 标题与正文 |
| 次文字 | `#6b7280` | 辅助说明 |
| 主强调色 | `#1ec8b5` | 导航激活、等级徽章、主按钮 |
| 暖黄色 | `#f6c453` | 金币、奖章、数值高亮 |
| 粉色 | `#ff8fa3` | 危险提示、扣分、撤回按钮 |
| 浅青色 | `#dffaf4` | 积极行为卡片底 |
| 浅粉色 | `#ffe8ed` | 需要改进卡片底 |
| 描边色 | `#f1e7dd` | 卡片边框、分割线 |

## 圆角与阴影
- 页面主卡片：`28px`
- 小卡片：`24px`
- 徽章/芯片：`999px`
- 按钮：`18px`
- 阴影：以柔和投影为主，避免后台风的硬阴影
- 外描边：优先使用 1px 暖白描边，必要时叠加内阴影

## 字体与信息层级
- 页面主标题：粗体、深色、大字号
- 卡片主标题：中粗体
- 说明文字：中灰色
- 数值信息：使用彩色圆角芯片包裹，避免纯文本堆叠

## 组件外观规则
### 导航
- 顶部导航采用胶囊式标签
- 激活态为深色底或主色底，带轻微上浮阴影
- 非激活态保留轻底色和图标

### 卡片
- 使用暖白底与大圆角
- 顶部可放等级徽章或状态角标
- 插画区与信息区分层清晰
- 数值使用彩色小芯片展示

### 按钮
- 主按钮：青绿色渐变或纯色，白字
- 次按钮：白底描边
- 危险按钮：粉红浅底+红色文字
- hover 只做轻微上移和阴影增强

### 弹窗与抽屉
- 顶部信息头更强，支持头像、姓名、宠物名、等级、金币
- 主体内的功能项以卡片按钮承载
- 最近操作记录优先用右侧抽屉或浮层面板呈现

### 图标与插画
- 图标统一为圆润线条或双色面性图标
- 图标底座使用圆角色块
- 宠物与商品插画都保持暖色、圆润、轻描边

## 页面落地原则
- 优先统一 `MainLayout`、`PetCard`、`ScorePanel`、`ShopItemCard`
- 旧表格页保留数据结构，但外层卡片、筛选条和按钮样式全部换新
- 最近操作记录入口固定放在打分弹窗右上区域和系统设置日志页中
