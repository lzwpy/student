# 最近操作记录交互说明

## 目标
- 在打分弹窗和日志页中查看最近操作
- 展示打分与购买两类记录
- 支持教师撤回可逆操作

## 交互入口
- `ScorePanel` 右上角放置“最近操作记录”按钮
- `系统设置 > 操作日志` 页面显示完整时间线

## 列表项结构
- 操作类型：`SCORE` / `PURCHASE`
- 标题：例如“英语课文背诵和单词默写”或“购买了星星贴纸”
- 学生名
- 时间
- 数值变化：EXP、金币
- 状态：正常 / 已撤回
- 操作按钮：撤回

## 撤回规则
### 打分记录
- 反向扣回或返还本次变动的经验值与金币
- 撤回后列表项显示“已撤回”
- 已撤回记录不可再次撤回

### 购买记录
- 返还本次消耗金币
- 若商品有有限库存，则回补库存
- 已撤回记录不可再次撤回

## 推荐接口
### 查询最近操作
- `GET /api/operations/recent?classId=1&limit=10`

返回项建议：
```json
{
  "id": 101,
  "actionType": "SCORE",
  "studentId": 2,
  "studentName": "李昱成",
  "title": "英语课文背诵和单词默写",
  "summary": "EXP +1 金币 +1",
  "expChange": 1,
  "coinChange": 1,
  "createdAt": "2026-03-19 16:37:12",
  "reverted": false,
  "revertible": true
}
```

### 撤回
- `POST /api/operations/{id}/revert`

## 前端展示建议
- 最近操作面板采用右侧抽屉或大弹窗
- 列表项使用圆角卡片
- 正向操作用青绿色标签，购买用黄色标签
- 撤回按钮用浅红色描边按钮
- 已撤回项降透明并加状态芯片
